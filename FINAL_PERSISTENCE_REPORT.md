## 🔄 Механизм работы
```
1. При запуске: HypothesisManager → load_from_file() → загрузка из hypotheses_data.json
2. При изменении: любая операция → save_to_file() → сохранение в hypotheses_data.json
3. При перезапуске: повтор с шага 1
```
