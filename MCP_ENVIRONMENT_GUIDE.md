# 🔄 Руководство по перезагрузке окружения MCP

## Что такое "перезагрузка окружения"?

**Окружение (environment)** - это контекст, в котором запущена ваша программа, включая:
- 🔌 Подключенные MCP серверы
- 📦 Загруженные библиотеки
- 🔐 Переменные окружения
- ⚙️ Конфигурационные файлы
- 💾 Кэшированные данные

Когда вы **добавляете новые MCP серверы** в конфиг, система их не видит до **перезагрузки окружения**.

## Почему нужна перезагрузка?

Когда система запустилась в первый раз:
- ❌ Файл `cline_mcp_settings.json` был пуст
- ❌ MCP серверы ContentOps еще не были добавлены
- ❌ Система их не знает

После того, как мы добавили 7 сервисов:
- ✅ Файл обновлен с новыми серверами
- ⏳ Но запущенная система еще не знает об этом
- ⏳ Нужно "пересказать" системе о новых сервисах

## Как перезагрузить окружение?

### Способ 1: **Закрыть и открыть заново** (Самый простой) ✅

Если вы используете Visual Studio Code с расширением Cline:

1. **Закройте окно/вкладку** с текущей сессией
2. **Откройте новую сессию** в Cline
3. **Система автоматически** загрузит обновленную конфигурацию

```
Действие: Ctrl+W (Close Tab) или Cmd+W на Mac
Потом: Заново откройте Cline
```

### Способ 2: **Перезагрузить IDE** (IDE - это VS Code)

1. Закройте VS Code полностью
2. Откройте его снова
3. Система перезагрузит все окружение

```bash
# На Mac:
# 1. Command + Q (выход из VS Code)
# 2. Откройте VS Code заново
```

### Способ 3: **Перезагрузить терминал** (если используете CLI)

```bash
# Закройте текущий терминал
# Откройте новый терминал
# Система автоматически перечитает cline_mcp_settings.json
```

## Что происходит при перезагрузке?

```
Шаг 1: Система читает cline_mcp_settings.json
        ↓
Шаг 2: Находит 7 новых MCP серверов
        ↓
Шаг 3: Пытается подключиться к каждому
        ↓
Шаг 4: Загружает инструменты и ресурсы
        ↓
Шаг 5: Теперь доступны все функции ContentOps!
```

## Проверка подключения

После перезагрузки вы можете проверить:

### Вариант 1: Посмотреть логи
```bash
# Если видите в логах:
# "Connected to contentops-writer"
# "Connected to contentops-editor"
# и т.д. - значит все работает!
```

### Вариант 2: Попробовать использовать
```python
# После перезагрузки этот код должен работать:
access_mcp_resource("contentops-writer", "writer://publish")
```


## Проблема: "Not connected" error

Если видите ошибку "Not connected":

### Причины:
1. ❌ Окружение еще не перезагружено
2. ❌ MCP сервер недоступен (offline)
3. ❌ Неправильный URI ресурса
4. ❌ Неверный формат авторизации

### Решение:
```bash
# 1. Перезагрузите окружение (один из способов выше)
# 2. Проверьте cline_mcp_settings.json
# 3. Убедитесь, что URL серверов доступны:
curl -I https://planner-mcp-production.up.railway.app/mcp/writer

# 4. Проверьте логи:
cat /Users/a.porubov/Library/Application Support/Code/User/globalStorage/saoudrizwan.claude-dev/settings/cline_mcp_settings.json
```
