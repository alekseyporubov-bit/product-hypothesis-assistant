## 📁 Технические детали
- **Файл хранения**: `hypotheses_data.json`
- **Формат**: JSON с UTF-8 кодировкой
- **Структура**: Объект с ключами по ID гипотез, содержащий полные данные о гипотезах
- **Механизм**: Автоматическое сохранение при каждом изменении, автоматическая загрузка при старте

## 🔄 Процесс работы системы
```
1. Приложение запускается → HypothesisManager().__init__() → load_from_file()
2. Пользователь создает гипотезу → create_hypothesis() → save_to_file()
3. Пользователь добавляет доказательства → add_evidence() → save_to_file()
4. Пользователь валидирует гипотезу → validate_hypothesis() → save_to_file()
5. Пользователь записывает результат → record_outcome() → save_to_file()
6. Приложение перезапускается → повтор с шага 1
```
