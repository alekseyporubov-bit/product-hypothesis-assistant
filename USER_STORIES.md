# 📋 USER STORIES: Product Hypothesis Assistant

Полное описание пользовательских сценариев в формате Gherkin и User Story.

---

## 🎯 ОСНОВНАЯ БИЗНЕС-ЗАДАЧА

Система помогает продуктовому менеджеру подготовить количественно обоснованное заключение о потенциале продуктовой гипотезы (фичи) в виде score уверенности (0-100).

---

## 👥 ПЕРСОНЫ

### Основная персона: Продуктовый менеджер (Product Manager)
- Делает решение о запуске новой фичи
- Хочет иметь данные для обоснования
- Ищет доказательства за и против
- Нужна система для структурированной оценки

---

## 📖 USER STORIES В GHERKIN

### STORY #1: Создание новой гипотезы

```gherkin
Feature: Создание и управление гипотезами
  
  Scenario: Продуктовый менеджер создает новую гипотезу
    Given Пользователь находится на главной странице приложения
    When Он кликает кнопку "Создать новую гипотезу"
    Then Открывается форма создания гипотезы
    
    When Он заполняет все обязательные поля:
      | Поле | Значение |
      | Название фичи | Тёмный режим в приложении |
      | Описание | Добавление тёмного режима для удобства пользователей |
      | Проблема | Пользователи жалуются на боль в глазах ночью |
      | Целевые пользователи | Активные пользователи приложения ночью |
      | Ожидаемый результат | Увеличение времени использования на 15% |
    
    And Он кликает кнопку "Создать гипотезу"
    Then Гипотеза успешно создается
    And Система возвращает уникальный ID гипотезы
    And Гипотеза появляется в списке гипотез
    And Система переводит в раздел "Просмотр гипотезы"
```

### STORY #2: Добавление доказательств

```gherkin
Feature: Сбор доказательств для гипотезы

  Scenario: Добавление доказательства за гипотезу
    Given Гипотеза открыта в режиме редактирования
    When Он заполняет форму доказательства:
      | Поле | Значение |
      | Тип | MARKET_RESEARCH |
      | Название | Исследование Nielsen о тёмных интерфейсах |
      | Описание | 78% пользователей предпочитают тёмный режим ночью |
      | Источник | Nielsen Norman Group 2026 |
      | Уверенность | 0.95 (95%) |
      | Поддерживает гипотезу | ДА |
    
    And Кликает "Добавить доказательство"
    Then Доказательство добавляется к гипотезе
    And Система пересчитывает score гипотезы
```

---

### STORY #3: Валидирование гипотезы

```gherkin
Feature: Оценка гипотезы

  Scenario: Получение Score для гипотезы
    Given Гипотеза создана с несколькими доказательствами
    When Пользователь кликает кнопку "Валидировать гипотезу"
    Then Система анализирует все доказательства
    And Вычисляет Score по шкале 0-100
    And Возвращает:
      - Score (0-100)
      - Recommendation (proceed/investigate/reject)
      - Confidence (0-1)
      - Reasoning (обоснование)
    
    When Score > 70
    Then Рекомендация: "PROCEED" (Воплощать)
    
    When Score 40-70
    Then Рекомендация: "INVESTIGATE" (Исследовать дальше)
    
    When Score < 40
    Then Рекомендация: "REJECT" (Отклонить)
```

---

### STORY #4: Научные исследования

```gherkin
Feature: Автоматический поиск поддерживающих исследований

  Scenario: Получение исследований по гипотезе
    Given Гипотеза валидирована
    When Пользователь открывает раздел "Научные исследования"
    Then Система ищет исследования по ключевым словам
    And Выполняет запрос к открытым источникам
    And Отображает найденные исследования с:
      - title (название)
      - authors (авторы)
      - year (год)
      - url (ссылка)
      - relevance (релевантность)
```

---

### STORY #5: Запись результатов

```gherkin
Feature: Отслеживание реальных результатов

  Scenario: Запись результатов после релиза фичи
    Given Фича была выпущена и проверена
    When Продуктовый менеджер кликает "Записать результат"
    Then Открывается форма с полями:
      - Была ли фича успешной? (Да/Нет)
      - Фактический результат (текст)
      - Выученные уроки (текст)
    
    When Пользователь заполняет и кликает "Сохранить"
    Then Результаты сохраняются
    And Гипотеза меняет статус на "COMPLETED"
```

---

### STORY #6: Анализ корреляции

```gherkin
Feature: Анализ точности предсказаний

  Scenario: Просмотр корреляции между предсказанием и реальностью
    Given Несколько гипотез были протестированы
    When Пользователь кликает "Анализ корреляции"
    Then Система показывает:
      - Total Tested (количество)
      - Accuracy (точность %)
      - Avg Prediction vs Actual (разница)
```
